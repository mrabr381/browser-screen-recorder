Browser Screen Recorder — live demo

Record your screen, then cut the video by deleting words from the transcript. A free, local alternative to Loom.

GitHub repo · README · Bundled sample: before / after

Read this first — stated plainly.
  • Screen capture needs a real browser (Chrome, Edge or Firefox) over HTTPS or localhost, and your permission: clicking Record opens the browser's own screen-picker (getDisplayMedia). Nothing is uploaded — the recording stays in your browser until you download it.
  • The Chrome extension has not been load-tested in a real Chrome yet — its JavaScript passes node --check and the manifest parses, but the first real Load-unpacked run is still an open check.
  • The Record / playback / download flow on this page is wired up but has not been verified in a real browser in this sandbox (there is no display here to capture). The transcript editor below is verified: its cut maths match the repo's Python tests and the shipped sample exactly.

1. Record your screen — in this page

Click Record, pick a screen, window or tab in the browser picker (tick “Share audio” if you want tab audio), then Stop. The recording plays back below and downloads as a .webm. This uses the same MediaRecorder + getDisplayMedia approach as the extension's extension/recorder.js.

Verified example — the numbers this demo must reproduce

    
Deleting words 27–35 (“These days a chicken leg is a rare dish.”, 9 words) removes 10.88–13.12 s and leaves a 31.368 s video: 73 words kept, kept ranges [[0.0, 10.88], [13.12, 33.608]]. Subtitle cue 4 (“Rice is often served in round bowls.”) re-times from 00:00:14,370 to 00:00:12,130, and the edited SRT has 9 cues instead of 10. These are the repo's own verified numbers (tests/test_transcript.py, sample_data/sample_output/cuts.json) — try the button above and check them.
